# Tokenizer Visualizer
**Задача:** Разработка инструмента для визуализации процесса токенизации текста и анализа эффективности кодирования.

**Технологии:** Transformers (Hugging Face), Python, NumPy.

**Ключевые моменты реализации:**
- Использование предобученного токенайзера GPT-2 для демонстрации алгоритма BPE (Byte Pair Encoding), который разбивает текст на подтокены на основе частоты их встречаемости в обучающих данных.
- Визуализация числовых ID токенов и их текстовых представлений, что позволяет понять, как модель преобразует естественный язык в последовательности, пригодные для обработки нейросетью.
- Реализация калькулятора токенов для оценки стоимости запросов к платным LLM API и планирования использования контекстного окна модели.
